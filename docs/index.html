From download to a clearer desktop.

  1. Install the Alpha

    Download the Windows 11 x64 installer from the official GitHub release.

  2. Create a page

    Open DeskPages from its tray icon and choose + Page. Name it for the work you want to keep together.

  3. Make it yours

    Arrange your icons and configure navigation in Settings. Save an arrangement to restore later.

Before you install

DeskPages is an Alpha preview. The installer is unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Review the source, checksums and release notes before deciding to run it.

No account, telemetry or cloud upload. Windows installation, touchpad behavior and multi-monitor performance still need real-device validation.

Common questions

Does DeskPages replace Windows virtual desktops?

DeskPages organizes the icons on your original desktop into pages. It is focused on desktop files and shortcuts.

Where is the official download?

The download button links directly to the installer attached to the official AdamAbuToamy/DeskPages GitHub release. All releases also remain available on GitHub.

How do I uninstall it?

Uninstall through Windows Settings. If the agent is unavailable, use DeskPagesRescue.exe. Do not manually remove page metadata while icons are hidden.
