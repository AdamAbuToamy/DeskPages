# تجهيز الإصدار الأولي — 0.8.7 Alpha

تمت إضافة حركة مستقلة داخل حدود كل شاشة بدل إيقاف الأنميشن عند وجود شاشة إضافية.
الخيار الجديد: الإعدادات > خيارات إضافية > الشاشة الرئيسية فقط. يحتفظ بأيقونات
الشاشات الأخرى ظاهرة وفي مواضعها أثناء تغيير صفحة الرئيسية. لا ينقل الملفات على
القرص ولا يحولها إلى تثبيت دائم. الحواف المشتركة بين الشاشات متروكة للسحب الطبيعي.

اختبارات المحاكاة تشمل 1006 توزيعات، الاتجاهين، وضع جميع الشاشات أو الرئيسية فقط،
و121 نقطة زمنية لكل حركة. محاكاة التنظيم تشمل إحداثيات سالبة وخمسة مقاييس للبكسلات
وحفظ الحالة وإعادة قراءتها وفصل الشاشة وإعادتها. اختبار الضغط استخدم 500 ملف
تجريبي و400 عملية محفوظة مع التراجع والإعادة وفحص البصمات. اختبارات إنهاء العملية
تتحقق من الاستعادة بعد توقف حقيقي لعملية الاختبار، مع محاكاة Explorer.

اختبار الواجهة المعزول بالعربية والعبرية والإنجليزية يشمل خيار الشاشة الرئيسية
والتراجع في الواجهة عند فشل الحفظ. لا يعني هذا اختبار واجهة ويندوز الأصلية على
جميع الأجهزة. أضيف محاكي DWM يعمل على شاشة واحدة داخل ويندوز دون الحاجة لشاشة
إضافية، لكنه لم يعمل هنا لأن بيئة البناء ليست ويندوز. يُشغّل عبر
Simulate-Monitors.cmd. توضح VERIFICATION.txt النتائج النهائية وحدودها.

المثبّت مخصص Windows 11 x64 وغير موقّع بشهادة ناشر موثوقة. الترخيص MIT باسم
Adam Abu Toamy، مع إشعارات المكتبات وسياسة خصوصية محلية محدثة. لا يصح الإعلان
أن الإصدار مضمون لجميع الأجهزة أو أنه اختُبر بإعادة تشغيل هذا الحاسوب.

أضيف GitHub workflow يبني على ويندوز ويختبر ويجهز المثبّت والمصدر والبصمات.
النشر الصريح عبر Release/Publish-GitHub.ps1 ينشئ المستودع العام ويشغّل البناء؛
لا يظهر Pre-release إلا بعد نجاحه. لا يوجد داخل المصدر رمز وصول أو كلمات مرور.
النشر لا يُعد مكتملًا حتى يظهر رابط الإصدار ونتيجة Actions الفعلية.
