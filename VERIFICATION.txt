DeskPages 0.8.7-alpha.1 — engineering preview evidence

Target: Windows 11 x64; built on a Linux host against official .NET Framework
4.8 references, with MinGW-w64 for the native launcher/compositor. End users need
only the installer. This document is not Windows/hardware certification.

PASS: C#5 managed runtime, startup guardian, normal-user OLE broker, Rescue and
installer compilation; x64 native compositor and launcher compilation.
PASS: per-monitor production math/atlas simulator: 1006 layouts, both directions,
all/primary modes, 121 frames and 19 sampled columns per region; 41,619,370
assertions. Side-by-side, stacked, offsets/gaps, portrait and mixed pixel extents.
This tests the exact MonitorPlan.h offset/crop contract consumed by DWM visuals,
not GPU scheduling, driver behavior, physical DPI or measured frame rate.
PASS: production primary-only scope/layout policy: 50 page/reload scenarios, left
and right displays, negative origins, five pixel scales, unplug/replug, primary
profile identity, system-icon aliases, stationary coordinates and unchanged
file content/path/page ownership. Explorer geometry is a simulated adapter.
PASS: actual display-scope dispatcher and durable workspace commit with real
fixture files; three pages, visibility/layout policy, invalid command, injected
precommit failure/recovery, disable and unchanged permanent pin ownership.
PASS: external/internal drag-boundary geometry; shared screen edges are left
available for ordinary dragging. Secondary navigation is rejected in primary mode.
PASS: 400 seeded durable operations on 500 real temporary files, undo/redo and
content hashes; real process exits at four workspace transaction stages followed
by recovery. Generic page transaction crash/failure and restart-plan fixtures
also pass. Explorer and registry adapters are simulated; no real reboot occurred.
PASS: exact current page/settings UI sources compiled and exercised in Mono/Xvfb
in en/ar/he: compact pages, independent settings, four basic switches, no writes
while loading, debounced autosave, advanced collapsed, display-scope success and
failed-save UI synchronization, repeated resizes and no removed-tool requests.
UI rendering was visually inspected. This is not native Windows WinForms evidence.
PASS: complete portable validation runner, script encoding/current-host parser,
exact callback binding, real temp-file identity/layout/hash checks, 10k metadata
read tests, OLE mailbox contention and drag state/placement/retirement fixtures.
PASS: public-source preflight; workflow YAML and build-to-publish gating checked.
PASS: final embedded installer payload hash, managed/PE identities, architectures,
source fingerprint, script encodings and no user profile/page state in payload.

SKIP here: Windows PowerShell 5.1, Windows file-attribute semantics, native
WinForms/DWM/GPU/COM, actual installation/upgrade/uninstall, physical monitor
plug/unplug and mixed adapters, actual logon/reboots/power loss, physical touchpad
and OLE visuals. A previous C0000005 UI report was not reproduced or universally
certified fixed on this host. Never interpret a SKIP as a PASS.

Automated Windows CI is provided but has NOT been dispatched or observed passing
at package creation. It compiles/builds/tests on a Windows Server runner; it does
not certify Windows 11 device behavior. Explicit workflow publish=true is gated
on build success. No public repository/tag/Release is claimed by this package.

Simulate-Monitors.cmd: opt-in actual DWM two-monitor-image simulator on one real
Windows display, including pixel isolation checks; NOT executed on this Linux
host. Release/Start-SandboxAcceptance.ps1: opt-in isolated real-Explorer acceptance
with source mapped read-only, reports writable and network/clipboard disabled;
NOT executed here. The persistent-VM reboot scenarios remain documented separately.

Limits: unavailable isolated HWND capture, reset graphics devices, >40M atlas
pixels or >16,384 pixels per axis may use safe nonanimated switching. Touchpad
support is driver-dependent. Source/release notes describe the experimental
multi-monitor support. Installer is unsigned; author metadata is not trusted
Authenticode. File organization recovery is not a file-content backup.

Detailed portable run evidence is under Release/Evidence. Only an exact delivered
artifact/published-source build should be used for subsequent Windows acceptance.
