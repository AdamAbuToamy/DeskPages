# DeskPages 0.8.7 — نسخة Alpha

صفحات لأيقونات سطح مكتب ويندوز الأصلي، من تطوير Adam Abu Toamy.
تبقى الملفات في مساراتها الأصلية. البرنامج مستقل عن Microsoft.

نزّل المثبّت EXE وشغّله. اضغط أيقونة البرنامج بجانب الساعة لعرض الصفحات.
اضغط الصفحة مرتين لفتحها، أو أضف صفحة بزر +. قائمة الصفحة تتيح تغيير الاسم
وقفل الترتيب وحذف الصفحة الفارغة. لا يُسمح بحذف صفحة فيها ملفات.

الإعدادات نافذة مستقلة ومبسطة: السحب بلوحة اللمس، السحب بين الصفحات، الأنميشن
ورقم الصفحة، مع اللغة والحفظ التلقائي. «خيارات إضافية» تحتوي الاختصارات وتقليل
الحركة ووجهة الملفات الجديدة وخيار «الشاشة الرئيسية فقط».

عند توصيل شاشات إضافية تتحرك كل شاشة ضمن حدودها. عند تفعيل الشاشة الرئيسية
فقط تبقى أيقونات الشاشات الأخرى ظاهرة في مواضعها أثناء تبديل الصفحة. انقل
الأيقونة إلى الرئيسية لتصبح تابعة لصفحتها مجددًا. السحب بين الشاشات يعبر الحافة
المشتركة بشكل عادي؛ تبديل الصفحة بالسحب يستخدم الحواف الخارجية.

حفظ الترتيب واستعادته يعيدان تنظيم الصفحات والأيقونات، وليس محتوى الملفات.
حدد أيقونات سطح المكتب ثم استخدم قائمة البرنامج لتثبيتها على كل الصفحات.
عند تسجيل الدخول يبدأ البرنامج على Main. لا يعمل من BIOS أو قبل ويندوز.

دعم الشاشات المتعددة تجريبي واختُبر بالمحاكاة هنا. لا تدّعي النتائج اختبار جميع
تعريفات الشاشات أو أجهزة التاتش باد. الهدف Windows 11 x64 مع .NET Framework 4.8.
ملفات OneDrive السحابية ذات reparse points خارج نطاق الإدارة. عند تعذر الالتقاط
المعزول أو تجاوز حدود موارد الرسوميات يكون الانتقال مباشرًا لحماية العرض.

المثبّت غير موقّع بشهادة ناشر موثوقة؛ قد يظهر تحذير من ويندوز. لا تُعطّل الحماية.
احذف البرنامج من إعدادات ويندوز. إذا تعطل، شغّل DeskPagesRescue.exe لاستعادة
العرض. لا تحذف بيانات الصفحات يدويًا أثناء إخفاء الأيقونات.

Validate.cmd يشغّل الاختبارات الآلية. Simulate-Monitors.cmd يشغّل محاكي DWM
لشاشتين على شاشة واحدة في جلسة ويندوز فعلية، دون تغيير الملفات أو إعداد الشاشات.
نتائج الاختبارات وحدودها في VERIFICATION.txt، وتعليمات النشر في Release/BUILD.md.
الخصوصية والترخيص في PRIVACY.txt وLICENSE.txt. لا حسابات أو تتبّع أو رفع بيانات.
